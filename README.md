# System Design with Param

Notes, whiteboards and code from the [**System Design with Param**](https://www.youtube.com/@SystemDesignWithParam) YouTube channel.

Every topic follows the same format: **theory → design → build → break it**. We explain the concept, design it on a whiteboard, build a small working version, then break it on purpose and fix it.

## Using the whiteboards

- **PNG:** `*-initial.png` is the board before the lesson starts, and `*-final.png` is how it looks at the end.
- **Excalidraw:** go to [excalidraw.com](https://excalidraw.com) and drag the `.excalidraw` file onto the canvas. Each board is a pair of frames: initial on the left, final on the right.
